# Imágenes del catálogo de estudios

Colocar aquí los archivos reales entregados para `st_competidores.logo`.
La ruta pública será `/studies/competitors/<archivo>`, por ejemplo un archivo
WebP o PNG con nombre estable. No hay imágenes ni marcas ficticias precargadas.

Los enlaces HTTPS externos también son admitidos. La guía usa texto plano;
un logo ausente o fallido muestra una alternativa textual.
